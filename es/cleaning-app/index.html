ANTES DE EMPEZAR

Lo que quizá te estás preguntando.

¿Tengo que pasar todo mi negocio de una vez?

No. Empieza con un cliente y su próximo trabajo. Añade otros clientes y servicios cuando quieras. Antes de compartir un enlace de reservas, sí necesitas definir tus servicios y disponibilidad.

¿La Aplicación Web ya incluye un enlace de reservas?

Sí. Incluye enlaces públicos para reservar y pedir cotización. La Configuración del Flujo de Reservas es el servicio separado para una Página de Reservas personalizada más confirmación al cliente, alerta para ti, Rastreador Privado de Consultas y seguimiento inteligente. Actualmente está en $49.99 pago único (precio regular $99).

¿Mis clientes pueden usar otro idioma?

Sí. La Aplicación Web y las páginas para clientes admiten español, inglés, francés y criollo haitiano. Puedes elegir el idioma de los correos al cliente por separado del idioma de tu Aplicación Web.

¿La Aplicación Web cobra a mis clientes?

La Aplicación Web registra los pagos. Tú recibes el dinero por el método elegido y después lo confirmas en la Aplicación Web.

¿Tengo que descargarla de App Store o Google Play?

No. Es una Aplicación Web que funciona desde el navegador. Puedes añadirla a tu pantalla de inicio y abrirla y usarla como una app en tu teléfono o tableta.

¿Qué pasa al terminar el período gratis?

Puedes continuar por $5.99/mes si quieres. La suscripción de la Aplicación Web de Limpieza es separada de la Configuración del Flujo de Reservas.
